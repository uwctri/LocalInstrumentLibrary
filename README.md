# Local Instrument Library

## What does it do?
The Local Instrument Library REDCap External Module provides a centralized repository for browsing, sharing, and installing data collection instruments across REDCap projects within your organization.

Users can search and filter instruments by category, view field structures, preview form layouts, and install instruments directly into active REDCap projects with a single click. Project users can also submit new instruments or updates via ZIP packages or direct export from existing projects. REDCap administrators have access to a dedicated admin panel to review, edit, approve, or decline pending submissions. An optional public-facing library page allows unauthenticated users to explore available instruments.

## Things to do after install
Before launching the module across your organization, you should navigate to the module settings page and review default configuration. A custom setting screen is availble on the Instrument Library Administration page in the Control Center.


## Dependencies

* **Alpine.js** (`js/alpine.min.js`) - Auto-updating via GitHub Actions weekly workflow.
